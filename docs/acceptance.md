# 开发验收记录

验收日期：2026-11-14。版本：0.1.0-alpha.1。目标：DeepSeek Harness 0.2.2-rc.2。以下区分已运行验证与仍需宿主实机验收的项目。

## 自动化

`npm run check` 构建客户端并执行 Node 测试。29 项测试全部通过（含发布前新增的所有者 RPC 边界回归）。当前测试覆盖：

- 核心任务服务：计划不可整体覆盖、稳定 ID、复杂度决策、当前/指定父级增补、歧义拒绝、依赖与循环校验、版本隔离、直接完成、取消、祖先重开、子树权限、并发增补和任务排序。
- 持久化：文件冷恢复、未完成任务暂停、状态损坏不覆盖、第二写入者拒绝、通知保留。
- 调度：单并发队列、逐项通知、父等待释放名额、孙任务仅通知直接父、深度上限行内回退、行内子任务与待执行事项死锁回归。
- 客户端：编译后模块在 jsdom 挂载，槽位键、父级增补指令、本会话输入、任务跳转、工具 portal 挂载和会话切换清理。
- 所有者 RPC：匿名、缺少 browserPeer、外部访客拒绝；绑定浏览器和显式所有者可访问。
- **真实 DSH rc.2 集成**：加载发布版 Cordis / AgentLoop / Session JSONL / Subagents / Spawn，实现模型调用规划工具、行内执行、真实子会话和孙子会话、结构化结果、直接父通知持久化；第二轮消息不改变原计划。

模型集成使用确定的测试适配器，不消耗真实模型 API，不等于真实模型规划效果评估。

## 流程与截图

在 `http://127.0.0.1:4173` 的独立验收环境已验证：

1. 首条目标经模型工具生成右侧持久任务树。
2. 继续指令发送后创建真实子会话；完成后任务勾选、主会话收到通知。
3. 重启服务并刷新后，保留计划 UUID、稳定任务 ID、完成状态和已有消息。此次样式调整过程中多次重启，同一计划与三个任务仍保留。
4. 本地页面在会话左侧 iframe 展示，关闭后恢复完整对话；工具状态按会话隔离。
5. 任务增补、筛选、深浅主题、窄屏区域及对话/工具切换。

## 发布候选包验证

源码已按 domain/application/storage/server/client 分层，包仅保留运行产物。`npm run check:package` 将实际 tgz 安装到工作区外的临时独立目录，验证生产 peer 解析、服务端入口、ModuleLoader、无开发依赖及无原型/JSX/脚本，并以该安装包执行真实 DSH AgentLoop 集成测试。报告与 SHA-256 位于 dist；它不等于完整用户 profile 安装。Linux/Windows CI 已配置，远端结果尚未取得。

## 安装前仍需验证

- 用户完整 DSH 桌面/Web profile 中安装 `.tgz`、客户端依赖自动加载、原生左右侧栏与窗口布局。
- 真实用户模型自动规划和多轮自然语言增删改的质量。
- 已安装浏览器、编辑器、终端和第三方插件的名称映射、执行能力与专用渲染器。
- 第三方网页 CSP / X-Frame-Options、认证会话及自动化浏览器控制；默认 iframe 无法保证所有页面可嵌入。
- 比 rc.2 更新的宿主版本；本版 engines 明确锁定 rc.2，不将未测试版本声明为兼容。

没有修改用户现有 DSH profile，未推送到 GitHub 或发布插件到市场。
